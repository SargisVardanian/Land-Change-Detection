# Dataset Curriculum

No single public dataset gives all of the following at once:

- segmentation
- text descriptions
- old/new pairs
- seasonal diversity
- multispectral EO coverage

The platform should therefore use a curriculum rather than search for one perfect dataset.

## Segmentation / Taxonomy Alignment

- OpenEarthMap
- Dynamic World
- ESA WorldCover

## Seasonal / Temporal Robustness

- BigEarthNet / BigEarthNet.txt
- DynamicEarthNet
- custom Sentinel manifests

## Change Detection / Semantic Change

- OSCD
- SECOND / OpenMapCD
- LEVIR-CD
- LEVIR-CC
- LEVIR-MCI

## Project-Specific Extension

Custom Sentinel manifests should be used to add:

- Armenia-specific seasonality
- irrigated vs non-irrigated patterns
- dry vs wet regional dynamics
- local validation events
